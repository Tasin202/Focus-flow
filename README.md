## ✨ Why FocusFlow?

The Pomodoro technique is simple: work in focused sprints, then take short breaks. Most timer apps are cluttered, full of ads, or ask for an account. FocusFlow is none of that.

- 🚫 **No ads, no accounts, no tracking**
- 📴 **Works fully offline**
- 🔒 **Your data never leaves your phone**
- 🆓 **Free and open source**

## 🎯 Features

| | |
|---|---|
| ⏲️ **Smart timer** | Focus, short break and long break with a smooth progress ring. Stays accurate even when your phone sleeps. |
| ✅ **Tasks** | Add tasks and see how many Pomodoros each one took. |
| 📊 **Statistics** | Daily totals, streaks, a 7-day chart and full session history. |
| 🎨 **Make it yours** | Light/dark theme, 5 accent colors, 3 sounds, vibration. |
| ⚙️ **Flexible** | Custom durations, auto-start breaks, end-of-session warning. |

## 📱 Install

1. Tap **Download for Android** above (or open the [Releases page](https://github.com/YOUR-USERNAME/focusflow/releases/latest)).
2. Open the downloaded `FocusFlow.apk`.
3. If Android asks, allow **"Install unknown apps"** for your browser.
4. Done, open FocusFlow and start focusing!

> The app isn't on the Play Store yet, so Android shows a standard warning for apps installed from outside it.
